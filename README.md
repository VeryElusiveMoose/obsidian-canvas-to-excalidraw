# Canvas to Excalidraw

Converts an Obsidian Canvas into an Excalidraw drawing for Obsidian.

## Before you start

- You need the **Excalidraw** plugin installed and turned on. If it's missing, this plugin offers to get it for you.
- The result is an Obsidian Excalidraw drawing, opened by the Excalidraw plugin inside Obsidian. It isn't a standalone file for excalidraw.com.

## How to use

Right-click a canvas and choose **Convert to Excalidraw**. The drawing appears next to it and opens. Your canvas is never changed, and images, notes and PDFs stay linked rather than copied.
